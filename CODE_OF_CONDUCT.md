# Code of Conduct

We want this project to be a welcoming place for people with different backgrounds and experience levels. Be respectful, constructive, and patient. Critique ideas and code without attacking people.

Unacceptable behavior includes harassment, discrimination, personal attacks, publishing someone else's private information, and deliberately sharing credentials or private data. Project maintainers may edit or remove harmful content and may close or restrict participation for repeated or severe violations.

To report a conduct concern, contact the maintainers through a private channel offered by the repository. Do not put sensitive details in a public issue. The project contact link will be added to the README when the maintainer provides it.
