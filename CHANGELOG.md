# Changelog

Notable project changes are recorded here.

## 0.1.0 — first public release candidate

- Documented the full data construction, trajectory evaluation, LoRA SFT, and Slime GRPO workflow.
- Added a centralized ready-to-run dataset bundle and module launcher.
- Removed unrecoverably text-corrupted rows from release datasets and anonymized order/tracking identifiers and retailer deep links.
- Added first-time GitHub publishing instructions, contribution and security policies, dataset/third-party notices, and citation metadata.

This is the project's first release and will continue to improve. The final GitHub release date, author profile, and repository URL will be filled in when the repository is created.
