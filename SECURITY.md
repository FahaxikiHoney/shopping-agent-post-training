# Security policy

This is the first public version. Please do not report suspected vulnerabilities together with exploit details, credentials, or private data in a public issue.

Use GitHub's private vulnerability reporting feature if it is enabled for the repository. Otherwise, contact the maintainer through the private contact channel listed in the README. The public contact link will be added before publication. Please include the affected path/version, impact, and a minimal reproduction without real secrets.

Do not send API keys, access tokens, `.env` files, model checkpoints, customer data, or production logs. We will acknowledge reports and coordinate a fix and disclosure timeline with the reporter.
