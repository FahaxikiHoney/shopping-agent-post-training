# ReAct LoRA SFT 显存与启动说明

从项目根目录运行统一入口，默认使用 `sft_data/ready_to_run/react_sft/` 中清理后的 875/100/100 数据切分：

```bash
python scripts/run_module.py sft --model-path /path/to/Qwen3-0.6B
```

Windows 可在 Git Bash 中运行同一命令。首次启动会创建或复用虚拟环境并安装训练依赖。模型路径、精度、batch size 与梯度累积设置应按 GPU 显存调整。

更多模型准备、训练参数和故障排查请看 [`docs/03-sft-lora.md`](../docs/03-sft-lora.md) 与 [`docs/06-code-and-data-map.md`](../docs/06-code-and-data-map.md)。训练数据格式和清理说明见 [`sft_data/ready_to_run/README.md`](../sft_data/ready_to_run/README.md)。
